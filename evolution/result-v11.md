# Fixture presentation diagnostic v1

The earlier Turnstile invocation reached its local Ready page and timed out
before provider loading. The owner reported no visible window. Neither its v3
report nor its process evidence retained window placement or focus. The later
visibility helper passed, but used different launch settings and content.

An independently selected local diagnostic now shares the provider fixture's
unchanged launch-option factory and trusted confirmation waiter. It serves only
the local Ready page with an explicit diagnostic notice. Its button confirms
visibility and closes; it can never initiate verification or submit a form.

`browserdriver.fixture-presentation.v1` and its independent v1 exclusive claim
retain reduced before/after-foreground and changed waiting samples: numeric
bounds, closed window/page state, focus Boolean and available-screen bounds.
At most 32 samples are retained, preserving the first two; omitted transitions
are counted. Raw DOM, titles, exception prose, screenshots and other windows are
excluded. Actual human confirmation remains necessary. No resizing, workspace
switching, repeated focus requests or automated clicks mask the baseline.

Five-minute confirmation is clamped by a 330-second diagnostic operation limit;
the outer supervisor enforces 360 seconds plus ten-second cleanup. It must join
all owned processes and retain failure evidence. Unknown geometry cannot become
an inferred historical explanation. The baseline retains the fixture's inherited
Playwright sandbox default, unlike the explicitly sandboxed earlier helper;
that difference is disclosed, not asserted to cause invisibility. No provider
contact or runtime qualification is included in this isolated local comparison.

The diagnostic is separately authorized and skipped by default. Provider fixture
v3, verification diagnostics v3, driver v6, UWS contracts and consumed report
meaning are unchanged. Focused offline verification precedes a bounded manual
desktop run; implementation alone does not close that browser verification gate.
